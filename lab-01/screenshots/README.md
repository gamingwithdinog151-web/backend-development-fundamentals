# Screenshots Directory

Save your captured browser or Postman screenshots into this directory with the following exact filenames:

1. `home.png`       - Screenshot of http://localhost:3000/ (GET /)
2. `about.png`      - Screenshot of http://localhost:3000/about (GET /about)
3. `time.png`       - Screenshot of http://localhost:3000/time (GET /time)
4. `not-found.png`  - Screenshot of http://localhost:3000/unknown (404 response)

These images will automatically render in the main `README.md`.
